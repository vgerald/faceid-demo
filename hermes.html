Text on the big GPU rig, vision on the small card, plus embeddings.

Persistent notes, per-task playbooks, and a curated, security-scanned registry.

🗄️ File & Code Ops
Read / write / patch, run Python, terminal, ripgrep, code review, git workflows.

🎙️ Media
Text-to-speech, transcription, YouTube study guides, image vision.
