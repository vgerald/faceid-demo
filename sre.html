Architecture & design

Everything runs in one place. The agent talks to a single model gateway, and that gateway is the only thing that ever reaches the models — so any model, from any provider, can be swapped in without rewiring the rest of the stack.

How a repair actually happens

When something in the home misbehaves, the agent works a fixed, evidence-first loop:

  1. Detect. A health signal — an integration down, a service error, a device that stops updating — raises an event.
  2. Diagnose. The agent reads logs and system state before touching anything, and pinpoints the root cause.
  3. Repair with least disruption. Reload a config before restarting a service; restart one container before the whole stack.
  4. Verify. The fix isn’t done until the affected pieces are observed actually working again.
  5. Notify & remember. A plain-language report reaches the household, and the lesson is recorded to avoid repeating it.

Design principles

The rules the whole system follows.

Local-firstInference stays on the home’s hardware. No telemetry, no cloud dependency.
Evidence before actionLook before you leap: diagnose from logs and state, never guess at a fix.
Least disruptive recoveryThe smallest safe change wins — a reload before a restart, one service before the whole stack.
Human-in-the-loopRisky operations are surfaced for approval, and every significant change is reported in plain language.
Verify, then reportA repair only counts as done once the system is observed healthy again.
Leave it betterEach incident is a chance to harden the stack against the next one.
